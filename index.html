Struktur Utama Bahasa Pemrograman C++

Setiap program C++ terdiri dari beberapa komponen dasar wajib yang menyusun kerangka eksekusi kode. Berikut komponen utamanya:

1. #include <iostream>

Header Preprocessor directive yang menyertakan library standar I/O (Input/Output) untuk fungsi seperti cout dan cin.

2. using namespace std;

Memberitahukan kompiler untuk menggunakan ruang lingkup standar (std) agar kita tidak perlu menuliskan std::cout setiap saat.

3. int main() { ... }

Fungsi utama program. Eksekusi kode C++ selalu dimulai pertama kali dari titik awal baris di dalam kurung kurawal fungsi main().

4. Komentar & return 0;

// Single-line atau /* Multi-line */ untuk catatan. return 0; menandakan program berakhir dengan sukses.

Contoh Struktur C++ Dasar: 
#include <iostream>  // Header library input-output
using namespace std; // Namespace standar

// Fungsi utama program C++
int main() {
    // Komentar: Menampilkan pesan
    cout << "Selamat Datang di SMKN 3 Sibolga!" << endl; 
    
    return 0; // Mengembalikan nilai status 0 (Sukses)
}

Tipe Data Primitif dalam C++

Tipe data menentukan jenis nilai yang dapat disimpan oleh sebuah variabel beserta alokasi ukuran memorinya di RAM:

Tipe Data Ukuran Memori Rentang Nilai / Deskripsi Contoh Penulisan
int 4 Byte (32 bit) Bilangan bulat (-2,147,483,648 s/d 2,147,483,647) int umur = 16;
float 4 Byte (32 bit) Bilangan pecahan/desimal (Presisi 6-7 digit) float nilai = 85.5f;
double 8 Byte (64 bit) Bilangan pecahan desimal presisi tinggi (15 digit) double pi = 3.14159265;
char 1 Byte (8 bit) Satu karakter tunggal ASCII (diapit tanda kutip tunggal) char gred = 'A';
string Bervariasi Kumpulan karakter/teks (diapit tanda kutip ganda) string nama = "Ahmad";
bool 1 Byte Kondisi logika: true (1) atau false (0) bool lulus = true;

Variabel & Konstanta

Variabel

Variabel adalah wadah di memori komputer untuk menyimpan data yang nilainya dapat diubah selama program berjalan.

// Deklarasi & Inisialisasi
int skor = 100;
skor = 150; // Nilai berubah
  • Tidak boleh diawali angka.
  • Sensitif terhadap huruf besar/kecil (Case Sensitive).
  • Tidak boleh memakai spasi atau kata kunci C++ (seperti int).

Konstanta

Konstanta menyimpan nilai tetap yang tidak dapat diubah setelah ditetapkan.

// Cara 1: Menggunakan const
const float PI = 3.14159;

// Cara 2: Menggunakan #define
#define HARGA_POKOK 50000

Mencoba mengubah nilai const akan menyebabkan error kompilasi!

Jenis-Jenis Operator C++

1. Operator Aritmatika

  • + Penjumlahan (a + b)
  • - Pengurangan (a - b)
  • * Perkalian (a * b)
  • / Pembagian (a / b)
  • % Sisa Bagi / Modulo (a % b)

2. Operator Perbandingan

  • == Sama dengan
  • != Tidak sama dengan
  • > Lebih besar dari
  • < Lebih kecil dari
  • >= Lebih besar sama dengan

3. Operator Logika & Increment

  • && AND Logika
  • || OR Logika
  • ! NOT (Negasi)
  • ++ Increment (+1)
  • -- Decrement (-1)

Syntax Input/Output & Escape Characters

C++ menggunakan stream cout << untuk mencetak ke layar monitor dan cin >> untuk menerima masukan keyboard pengguna.

Karakter Escape Umum (\)

  • \n Baris Baru (Newline)
  • \t Tabulasi Horizontal
  • \\ Mencetak Garis Miring (\)
  • \" Mencetak Tanda Kutip Ganda
Penjelasan Baris per Baris: 
int umur; 
cout << "Masukkan umur Anda: ";
cin >> umur; // Membaca input keyboard
cout << "Umur Anda: " << umur << "\ttahun\n";

Flowchart & Pseudocode

Topik 1: Penjumlahan & Perkalian

Pseudocode:

PROGRAM Perhitungan_Dua_Bilangan
DEKLARASI:
    a, b, hasilJumlah, hasilKali : INTEGER
ALGORITMA:
    INPUT a
    INPUT b
    hasilJumlah <- a + b
    hasilKali <- a * b
    OUTPUT "Hasil Penjumlahan: ", hasilJumlah
    OUTPUT "Hasil Perkalian: ", hasilKali
END PROGRAM

Flowchart Visual:

Implementasi C++ 

#include <iostream>
using namespace std;

int main() {
    int a = 12, b = 5;
    int hasilJumlah = a + b;
    int hasilKali = a * b;

    cout << "=== PERHITUNGAN BILANGAN ===" << endl;
    cout << "Bilangan A : " << a << endl;
    cout << "Bilangan B : " << b << endl;
    cout << "Hasil Penjumlahan: " << hasilJumlah << endl;
    cout << "Hasil Perkalian  : " << hasilKali << endl;

    return 0;
}
Soal Latihan Topik 1

Jika nilai a = 15 dan b = 4, berapakah nilai perkalian (a * b)?

Topik 2: Deret Genap

Pseudocode:

PROGRAM Deret_Angka_Genap
DEKLARASI:
    i, n : INTEGER
ALGORITMA:
    n <- 10
    FOR i <- 2 TO n STEP 2 DO
        OUTPUT i
    END FOR
END PROGRAM

Flowchart Visual:

Implementasi C++ 

#include <iostream>
using namespace std;

int main() {
    cout << "=== DERET ANGKA GENAP (2 - 10) ===" << endl;
    for(int i = 2; i <= 10; i += 2) {
        cout << i << " ";
    }
    cout << endl;
    return 0;
}
Soal Latihan Topik 2

Berapakah jumlah total seluruh angka pada deret genap dari 2 sampai 10 di atas (2 + 4 + 6 + 8 + 10)?

Topik 3: Cetak Bintang

Pseudocode:

PROGRAM Cetak_Bintang_Looping
DEKLARASI:
    i, n : INTEGER
ALGORITMA:
    n <- 5
    FOR i <- 1 TO n DO
        OUTPUT "* "
    END FOR
END PROGRAM

Flowchart Visual:

Implementasi C++ 

#include <iostream>
using namespace std;

int main() {
    int n = 5;
    cout << "Cetak Bintang " << n << " kali: " << endl;
    
    for(int i = 1; i <= n; i++) {
        cout << "* ";
    }
    cout << endl;
    return 0;
}
Soal Latihan Topik 3

Berapa kali simbol bintang * tercetak jika perulangan diubah menjadi for(int i=1; i<=8; i++)?

Flowchart & Pseudocode

Topik 4: Volume Balok & Tabung

Pseudocode Volume Balok & Tabung:

PROGRAM Hitung_Volume_Bangun_Ruang
DEKLARASI:
    p, l, t, r, volBalok, volTabung : REAL
    PHI = 3.14159
ALGORITMA:
    volBalok <- p * l * t
    volTabung <- PHI * r * r * t
    OUTPUT volBalok, volTabung
END PROGRAM

Flowchart Visual Volume Balok:

Implementasi C++ 

#include <iostream>
using namespace std;

int main() {
    float p = 10.0, l = 5.0, t = 4.0;
    float volBalok = p * l * t;

    cout << "=== VOLUME BALOK ===" << endl;
    cout << "Panjang: " << p << " cm, Lebar: " << l << " cm, Tinggi: " << t << " cm" << endl;
    cout << "Hasil Volume Balok = " << volBalok << " cm3" << endl;

    return 0;
}
Soal Latihan Topik 4

Berapakah volume balok jika panjang = 8 cm, lebar = 3 cm, dan tinggi = 5 cm?
